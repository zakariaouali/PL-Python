# Système Intelligent d’Optimisation Alimentaire

Projet réalisé dans le cadre du module de Programmation Linéaire.

## 🎯 Objectif du projet
Ce projet consiste à développer un système d’optimisation alimentaire basé sur la programmation linéaire afin de déterminer automatiquement une combinaison alimentaire optimale selon plusieurs contraintes nutritionnelles.

## 📚 Contenu du projet
- Résolution par la méthode graphique
- Résolution par la méthode du simplexe et dualité
- Validation avec Excel Solver
- Développement d’une application Python avec interface graphique

## 🛠️ Technologies utilisées
- Python
- Tkinter
- NumPy
- Matplotlib
- SciPy

## 🚀 Fonctionnalités
- Visualisation graphique des contraintes
- Calcul automatique de la solution optimale
- Affichage des tableaux du simplexe
- Exportation des résultats
